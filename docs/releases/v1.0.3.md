### 新功能

- **规则配置文件**：域名分组和归属规则可以一起导出为一个 YAML 文件，用任意编辑器一次修改多个分组后再导入。导入前会列出将要新增、修改、删除的内容，可选「以文件为准」或「只新增和更新」
- **明细覆盖率**：分布页显示最近 1 小时和所选时段里，有多少流量能对应到具体的连接，过去的空档不会掩盖现在的情况
- **采样间隔可调**：设置里可选 0.5 / 1 / 2 秒，默认从 2 秒改为 1 秒，漏采更少

### 改进

- 没有连接明细的流量分成两类显示：「漏采」是读取间隙里开了又关的连接，「补记」是 Mihomo-Monitor 没在运行时补回的流量；原来它们混在「未归类」「未采到连接明细」「未知入站」里
- 切换页面不再卡顿：查询不再占用界面，回到之前打开过的页面会先显示上次的内容，再在后台更新
- 读取更稳：实时速率断开时自行重连，不影响统计；偶尔读取失败只跳过一次；中断原因写入日志
- 统计数据来自更新的版本（例如用过开发版）时，不再启动失败，而是显示「需要更新」页面，可直接检查更新、下载安装

### 问题修复

- 修复连接计数偶尔超过内核总量时的少量多记，记录的流量累计始终等于内核自己的计数
