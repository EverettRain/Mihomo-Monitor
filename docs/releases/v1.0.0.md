### 首个正式版本

像 vnstat 一样统计 mihomo 内核的流量：直接读取你已经在用的 Clash 客户端，常驻托盘，几乎不占资源。

- **自动发现内核**：读取 Clash Verge Rev、Clash Party、Sparkle、ClashX Meta、Clash Nyanpasu 等客户端正在运行的 mihomo 内核；路由器（OpenClash 等）上的内核可以手动添加，多个内核可分别查看或合计
- **不漏记**：以内核自身的累计计数为准，按 15 分钟记录、永久保存；Mihomo-Monitor 退出或电脑睡眠期间，只要内核没有重启，流量会在下次读取时补回
- **概览**：今天、本周、本月、今年与累计用量，实时速率曲线，一年的流量热力图，近 7 / 30 / 90 天趋势
- **历史**：按小时、日、周、月、年翻看任意时段，用量最高的日子排行，自定义起止日期，导出 CSV
- **分布**：按实际出站节点、订阅、进程、入站和域名排行，展开进程可看它访问的域名
- **归属规则**：内核认不出进程的流量（容器、局域网设备经专用入站进来）可以按入站名称起名字，计入进程排行；「进程未识别」与「未采到连接明细」分开显示
- **域名分组**：给域名与 IP 打组，分布页按分组合并显示；支持粘贴文本、CSV、JSON、Clash / sing-box 规则集导入
- **计费周期**：每个订阅设置重置日与配额，显示本周期用量与预计周期末用量，到达提醒线时发系统通知，并与机场返回的已用量对照
- **后台常驻**：开机自启、托盘悬停显示今日用量；轻量模式下关闭窗口会连界面一起释放；应用内检查更新

macOS 版没有经过 Apple 公证，首次打开如提示“已损坏”，请运行 `xattr -cr /Applications/Mihomo-Monitor.app`。
